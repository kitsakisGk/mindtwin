# Paper

LaTeX source of the mindtwin paper.

- `main.tex`: entry point
- `sections/`: one file per section
- `references.bib`: bibliography
- `figures/`: figures (generated by scripts in `experiments/` where possible)

The PDF is built automatically by GitHub Actions on every push that changes `paper/`
(download it from the workflow run's artifacts). To build locally, install a TeX distribution
(e.g. MiKTeX or TeX Live) and run:

```bash
latexmk -pdf main.tex
```
